概要

「あとで見る / Watch Later」拡張機能（以下「本拡張機能」）は、ユーザーのプライバシーを尊重し、個人情報の収集を最小限に抑えることを基本方針としています。

収集する情報

本拡張機能が収集・保存する情報は以下のみです：

  • タイマーを設定したタブのURL・タイトル・メモ（ブラウザのローカルストレージにのみ保存）
  • SendGrid APIキー・送信元メールアドレス・送信先メールアドレス（ブラウザのローカルストレージにのみ保存）
  • スヌーズ設定・デフォルト時間などの設定値（ブラウザのローカルストレージにのみ保存）

これらの情報は お使いのブラウザ内にのみ保存 され、開発者を含む第三者のサーバーに送信されることはありません。

外部サービスへの通信

メール通知機能を使用する場合、本拡張機能はユーザー自身が設定した SendGrid APIキー を使用して、SendGrid社のAPI（api.sendgrid.com）に直接リクエストを送信します。

この通信はユーザーのブラウザから直接行われ、開発者のサーバーを経由しません。SendGrid社のプライバシーポリシーは こちら をご確認ください。

メール通知機能を使用しない場合、外部への通信は一切発生しません。

アクセス許可について

  • tabs：タイマー発火時に対象タブを前面に表示するため
  • alarms：指定時刻にタイマーを発火させるため
  • storage：設定・スケジュール情報をローカルに保存するため
  • notifications：OS通知を表示するため
  • <all_urls>：タイマー発火時にすべてのページにオーバーレイを表示するため

お問い合わせ

Overview

The "あとで見る / Watch Later" browser extension ("the Extension") is committed to protecting your privacy and minimizing the collection of personal information.

Information We Collect

The Extension stores the following information locally in your browser only:

  • URL, title, and reminder note of tabs you schedule
  • Your SendGrid API key, sender email address, and recipient email address
  • Extension settings such as snooze options and default timer duration

All of this information is stored exclusively in your browser's local storage and is never transmitted to the developer or any third-party server.

External Communications

If you choose to use the email notification feature, the Extension sends requests directly from your browser to the SendGrid API (api.sendgrid.com) using your own API key.

This communication goes directly from your browser to SendGrid — it does not pass through any server operated by the developer. Please refer to SendGrid's Privacy Policy for details.

If you do not use the email notification feature, no external communication occurs at all.

Permissions Explained

  • tabs: To bring the scheduled tab to the foreground when the timer fires
  • alarms: To trigger timers at the specified time
  • storage: To save settings and schedule data locally
  • notifications: To display OS-level notifications
  • <all_urls>: To display the reminder overlay on any page when a timer fires
